# ESP32-S3 离线语音小灯

原生 **ESP-IDF 6.0.x** 工程，针对 ESP32-S3 N16R8（16MB Flash / 8MB 八线 PSRAM）。
ESP-SR 2.5.5 提供 WakeNet9「嗨乐鑫」（官方模型 `wn9_hilexin`，Hi, 乐鑫）唤醒与 MultiNet7 中文离线命令识别；
LVGL 8.3.11 驱动 240×320 竖屏中文界面。无需 Wi-Fi、云端服务或手机。

## 使用

上电默认关灯，预选白色、亮度 35%。等待屏幕显示「离线语音已就绪」，
说 **「嗨乐鑫」**，看到「请说指令 · 自动续期」后，可以连续说多条灯控指令。
例如依次说「开灯」「红灯」「变色」「关灯」，中途无需重新唤醒。
每条命令后重置识别器并继续监听；单条识别器超时不会提前结束会话。
每识别并提交一条有效指令，重新开始 30 秒计时；连续 30 秒没有有效指令才回到等待唤醒状态。
普通声音、未识别的语句和识别器内部超时不会续期。

| 功能 | 示例指令 |
| --- | --- |
| 开灯 | 开灯、打开灯、打开台灯 |
| 关灯 | 关灯、关闭灯、关闭台灯 |
| 变色 | 变色 |
| 随机颜色 | 随机 |
| 颜色 | 红灯、黄灯、绿灯、蓝灯、紫灯、白灯、橙灯、青灯、粉色灯 |
| 颜色别名 | 红色、黄色、绿色、蓝色、紫色、白色、橙色、青色、粉色 |
| 颜色组合 | 打开红灯、打开黄灯等；粉色使用「打开粉色灯」 |
| 调亮 | 调亮、亮一点、调亮一点、增加亮度 |
| 调暗 | 调暗、暗一点、调暗一点、降低亮度 |
| 最高亮度 | 最亮（100%） |
| 最低亮度 | 最暗（10%） |

触摸屏采用深海蓝背景（`#0B1628`）、蓝色卡片和青色细线点缀，顶部「声控小灯」居中，提供居中图文开关、变色、九色快捷按钮、调亮和调暗按钮。
选色或换色会开灯；关灯保留当前颜色和亮度，断电恢复默认值。
亮度每次改变 10 个百分点，限制为 10%～100%。
调亮会开灯，调暗不会改变开关状态。
「最亮」「最暗」会直接开灯并设为 100% / 10%，保留当前颜色。
「随机」会开灯，保持当前亮度，从其他八种预设颜色中随机选择一种，不会连续选中同一颜色。
颜色圆点采用 1 像素细边框，选中项以青色边框区分。
屏幕只显示产品状态，诊断信息仅输出到串口。

## 接线

| 设备 | 信号 | GPIO |
| --- | --- | --- |
| ST7789V | MOSI / SCLK / CS | 17 / 16 / 5 |
| ST7789V | DC（RS） / RST / BL | 7 / 6 / 8 |
| FT6336U | SDA / SCL | 10 / 13 |
| FT6336U | RST / INT | 9 / 12 |
| ICS43434 | WS / SD / SCK | 2 / 1 / 42 |
| ICS43434 | L/R | GND（左声道） |
| WS2812 | DIN | 18 |

电源采用板载 3.3V，共地。触摸芯片地址为 `0x38`，软件轮询坐标，不依赖 INT。
屏幕以 SPI 40MHz、RGB565 工作，关闭反色以匹配实际灯光；麦克风以 16kHz、32 位左声道 I²S 采集，
转换成 16 位单声道后送入 AFE，再进行唤醒及命令识别。

## 原生 ESP-IDF 构建与烧录

在 **ESP-IDF PowerShell** 中进入本工程：

```powershell
idf.py set-target esp32s3  # 首次构建执行
idf.py build
idf.py -p COM3 -b 460800 flash
idf.py -p COM3 monitor
```

当前电脑可先运行以下环境激活脚本：

```powershell
. C:\Espressif\tools\Microsoft.v6.0.3.PowerShell_profile.ps1
```

`Ctrl+]` 退出串口监视器。烧录前关闭其他占用 COM3 的串口工具。
`idf.py flash` 会同时写入引导程序、分区表、应用和语音模型；
不能只烧录 `voice_light.bin` 到空白芯片。

| 分区 | 地址 | 大小 |
| --- | --- | --- |
| NVS | `0x9000` | 24KB |
| PHY | `0xf000` | 4KB |
| 应用 | `0x10000` | 4MB |
| 语音模型 | `0x410000` | 11.9375MB |

依赖版本由 `main/idf_component.yml` 和 `dependencies.lock` 固定；
首次构建需要联网下载，烧录后的设备完全离线工作。此分区布局不含 OTA。

## 代码位置与调试

- `main/board.h`：所有硬件引脚及触摸方向设置。
- `main/board.c`：ST7789、FT6336、I²S 驱动。
- `main/light.c`：统一灯光状态及 WS2812 RMT 驱动。
- `main/ui.c`：LVGL 中文图标界面。
- `main/voice.c`：音频处理、46 条命令短语和唤醒状态机。
- `main/ui_font.c`：Noto Sans CJK SC 字体子集，图标回退到 LVGL 自带字体。

LVGL 与灯光状态只在主任务中操作；语音任务通过队列提交状态和灯控命令。
麦克风采集与识别分开运行，SPI 使用 DMA 双缓冲，WS2812 使用 RMT DMA。
语音初始化出错时保留触摸控制，并显示「语音暂不可用」。

启动检查（重启设备并采集约 25 秒串口）：

```powershell
python tools/serial_check.py --port COM3 --seconds 25
```

日志应包含 PSRAM 容量、`FT6336 touch OK`、两个模型名称、`Ready: 46 phrases`、
麦克风初始 RMS/峰值。唤醒和识别会分别输出 `Wake detected` 和 `Recognized command`。
若触摸方向与实际屏幕装配不同，调整 `board.h` 中的 `TOUCH_SWAP_XY`、
`TOUCH_MIRROR_X`、`TOUCH_MIRROR_Y`。麦克风增益在 `voice.c` 的 `MIC_GAIN_SHIFT`
中设置：当前右移 14 位相当于 4 倍增益，右移 16 位为单位增益。

## 字体再生成

已提交生成后的字库，正常编译无需 Node.js 或字体转换工具。
修改界面文字后，将开源 [NotoSansCJKsc-Regular.otf](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese)
放入 `tools/font/`，执行：

```powershell
npm install --prefix tools --no-save lv_font_conv@1.5.3
node tools/generate_font.cjs
```

字体许可证见 `tools/font/OFL.txt`。
接口参考：[ESP-SR 中文文档](https://docs.espressif.com/projects/esp-sr/zh_CN/latest/esp32s3/index.html)。
